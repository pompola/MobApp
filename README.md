## Описание проекта

«Моя карта мест» — учебное мобильное приложение на React Native и Expo. Оно позволяет добавлять места на карту, открывать карточку выбранного места и прикреплять к нему фотографии.

## Реализованные возможности

- Отображение интерактивной карты на экране приложения.
- Начальная позиция карты — район Перми.
- Добавление метки долгим нажатием на карту на мобильном устройстве.
- Отображение добавленных меток на карте красными маркерами.
- Автоматическое название нового места с возможностью изменить его на экране деталей.
- Удаление места с карты с подтверждением; вместе с местом удаляется список его фотографий.
- Переход на экран подробной информации при нажатии на метку.
- Отображение широты и долготы выбранного места.
- Выбор одного или нескольких изображений из галереи устройства.
- Просмотр выбранных изображений в списке фотографий места.
- Удаление изображения с подтверждением действия.
- Проверка разрешения на доступ к фотографиям и вывод сообщения, если доступ не предоставлен.
- Отображение сообщения при ошибке загрузки карты.
- Типизация данных маркеров, изображений и параметров маршрута с помощью TypeScript.
- Навигация между экраном карты и экраном деталей с помощью Expo Router.

## Используемые технологии

- React Native
- Expo
- TypeScript
- Expo Router — файловая навигация
- React Native WebView — отображение веб-карты внутри приложения
- Leaflet — интерактивная карта
- OpenStreetMap — картографические данные
- Expo Image Picker — выбор изображений из галереи

## Требования для запуска

- Node.js LTS
- npm
- Expo Go на мобильном устройстве, совместимый с используемой версией Expo
- Подключение к интернету для загрузки библиотеки Leaflet и тайлов OpenStreetMap

## Установка и запуск

1. Скачайте или клонируйте репозиторий проекта.
2. Откройте терминал в корневой папке проекта — там, где находится `package.json`.
3. Установите зависимости:

   ```bash
   npm install
   ```

4. Запустите сервер разработки Expo:

   ```bash
   npx expo start
   ```

5. Откройте приложение Expo Go на телефоне и отсканируйте QR-код из терминала или страницы Expo Dev Tools. Компьютер и телефон обычно должны быть подключены к одной сети Wi-Fi.

6. Дождитесь загрузки приложения и проверьте карту, добавление меток и работу с фотографиями.

## Как пользоваться приложением

1. На главном экране отображается карта и подсказка по добавлению места.
2. Нажмите и удерживайте нужную точку карты, чтобы создать метку.
3. На карте появится красная метка с автоматически созданным названием.
4. Нажмите на метку, чтобы открыть экран «Детали места».
5. В поле «Название места» введите своё название и нажмите «Сохранить название». Название будет отображаться во всплывающей подписи метки на карте.
6. Чтобы удалить место, нажмите «Удалить место с карты» и подтвердите действие. Место и привязанные к нему фотографии будут удалены.
7. Нажмите «+ Добавить изображение» и выберите фотографии в системном окне выбора.
8. Чтобы убрать отдельную фотографию, нажмите «Удалить» под изображением и подтвердите действие.
9. Вернитесь на карту с помощью кнопки возврата в заголовке экрана.

## Принятые решения при реализации

- Для карты выбран Leaflet, встроенный в приложение через WebView. Это позволяет обрабатывать события карты и отображать метки без отдельного экрана веб-приложения.
- В качестве картографического источника используется OpenStreetMap.
- Данные маркеров и связанные с ними изображения объединены в общем React-контексте `MarkersContext`, чтобы они были доступны на экране карты и на экране деталей.
- Для перехода к деталям используется файловая маршрутизация Expo Router. Идентификатор и координаты места передаются как параметры маршрута.
- Новым местам присваивается название по умолчанию; пользователь может изменить его на экране деталей.
- Маркеры Leaflet оформлены собственным SVG-значком красного цвета, поэтому цвет не зависит от стандартных изображений Leaflet.
- Для выбора фотографий используется Expo Image Picker. Перед открытием галереи приложение запрашивает разрешение.
- Основные структуры данных описаны интерфейсами TypeScript в `src/types.ts`.

## Известные ограничения

- **Данные не сохраняются после полного перезапуска приложения.** Маркеры и список выбранных изображений хранятся в оперативном состоянии приложения. Постоянное локальное хранилище в текущей версии не реализовано.
- Для загрузки карты требуется интернет: библиотека Leaflet и тайлы OpenStreetMap загружаются из внешних источников.
- Если доступ к галерее запрещён, добавить фотографии нельзя, пока пользователь не предоставит разрешение в настройках устройства.
- Работа карты и выбора изображений зависит от платформы и версии Expo Go; основной сценарий следует проверять на мобильном устройстве.
- В текущей версии можно задать название места, но отдельного поля для подробного описания нет.

## Проверка перед сдачей

Рекомендуется проверить следующие сценарии на устройстве:

- карта загружается и перемещается;
- долгое нажатие добавляет красную метку;
- название места можно изменить, и оно обновляется во всплывающей подписи;
- удаление места убирает метку с карты;
- нажатие на метку открывает правильный экран деталей;
- координаты соответствуют выбранной метке;
- можно выбрать несколько фотографий и увидеть их в списке;
- удаление фотографии работает после подтверждения;
- приложение корректно сообщает об отказе в доступе к галерее и проблемах загрузки карты.
